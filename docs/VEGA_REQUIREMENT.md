Vega RequirementVega IT
REAL-TIME COLLABORATIVE INFINITE CANVAS

Task Description: Build a web platform that allows multiple users to work together on an infinite canvas realtime, with strong focus on creative tools and interactions that go beyond  standard Figma or digital whiteboard.

Users should be able to:
* Create a room and invite others via shareable link
* Work on a massive 2D infinite surface (with smooth zoom, pan and infinite scrolling)
* Use advanced tools for content creation

Technical Requirements:
Mandatory for MVP (2days):
* Real-time collaboration
* Infinite Canvas-Smooth zoom and pan (must perform well with 100+ objects)
* Multiple types of objects: text, shapes, images, sticky notes, audio recordings)
* Simple authentication (Guest mode + Username)
* responsive design

For High Scores-Creative technical Part:
1. Physics and interactions-objects should have physics (can be thrown, collide), attract/repel each other - using Matter.js or custom physics engine)
2. Mini-map + Radar- shows the real time location of other users of the canvas
3. Offline support - system should handle going offline and sync changes once getting back online.

Bonus Features (for those that want to stand out):
* Export to multiple formats (PNG, SVG, JSON)
* "Time travel" - Replay the entire session from the beginning.
